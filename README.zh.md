## Reflect / Refract / Act

- **Reflect**：先问这是谁的问题，哪些判断还只是猜测。
- **Refract**：试试别人提出的做法，或者顺着现场遇到的限制换一种试法。原来的做法更好，也可以保留。
- **Act**：做一个能被别人试用的版本，记录有效的部分和没解决的问题。

这三件事比先决定用哪种技术更重要。具体奖项和评审标准在赛前公布。
