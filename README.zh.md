# REFR/ACT「另一种介质」

[English](README.md) · [完整叙事：如果我们不曾相遇](docs/zh/into-a-different-medium.md)

**见人，以人为本。**

我们习惯问一个人做过什么，却很少坐下来，听听他为什么想做这件事。

光穿过不同介质，方向可能改变。人和想法也是如此。我们想创造另一种介质，让平时不会遇见的人有机会坐到同一张桌前，在作品还来得及改的时候，一起试一次。

> 若我们的世界不曾相遇，有些事便永远不会发生。

REFR/ACT 由高中生团队主导。上届黑客松面向全校开放，有 **120 人实际参与**。这一次，报名面向所有创作者，不以学校背景筛选。

## Reflect / Refract / Act

- **Reflect**：先看清是谁遇到了这个问题，哪些判断还需要验证。
- **Refract**：把没做完的东西交给别人试，看看反馈会怎样改变做法。
- **Act**：做出一个可演示的版本，说清哪部分跑通了、哪部分还没有。
