# PRISMS House Event: Jones’s Bizarre Adventure

[Playbook home](../../README.md) / [中文](../zh/prisms-house-event.md)

Jones’s Bizarre Adventure is a school game competition for PRISMS houses, separate from the [five-day REFR/ACT hackathon](schedule.md). Its dates, submissions and judging follow the [official House Event rules](https://refracthack.org/housegame/), not the main hackathon playbook.

## What teams make

Each house enters one team and submits one Python game. The theme is announced at kickoff. The build period is about three weeks, and the core gameplay must work with a joystick and eight action buttons, without a keyboard or mouse.

| Checkpoint | What teams prepare |
| --- | --- |
| Week 1 | Game concept, mechanic and role breakdown, and a GitHub repository. |
| Week 2 | A prototype with one complete playable round. |
| Week 3 | The final game, with the repository and instructions for running it. |
