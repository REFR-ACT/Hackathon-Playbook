# REFR/ACT 2027 event schedule

[Playbook home](../../README.md) / [中文](../zh/schedule.md)

**Five in-person event days, plus a setup day.** The event is planned for late March 2027 in the Princeton area, New Jersey, USA. The table uses local time and reflects the current plan. The [event website](https://refracthack.org) will publish the exact dates, venue, and final schedule.

**Participant applications are not open yet.** The application window takes place before Days 0–5. This page will link to the application when it opens. See the [participant guide](participant-experience.md) for review details. [Organizing team applications](../../README.md#join-the-2027-organizing-team) are separate.

| Day | Proposed run of show |
| --- | --- |
| **Day 0 · Setup** | The organizers prepare the venue, test equipment and networking, and rehearse the opening. |
| **Day 1 · Arrival and opening** | Partner exhibitors set up at 09:00. Participants arrive and the partner exhibition opens at 10:00. The exhibition closes at 16:00. The opening ceremony runs 18:30–22:00. Team roster submission opens at 22:00, and building starts after the ceremony. |
| **Day 2 · Build and workshops** | Keep substantial blocks for development, with optional introductory workshops, cross-team testing, and time to talk to other creators. |
| **Day 3 · Build and exchange** | Continue building, with workshops on interaction and prototype iteration. Lightning interview booking opens at 16:00. |
| **Day 4 · Team lock and demo prep** | Team rosters lock at 12:00. Project submissions stay open. Interview booking closes at 16:00, and interview slots are sent at 18:30. |
| **Day 5 · Project expo and closing** | Project submissions close at 01:00. The all-team expo and project judging run 09:00–11:30. Lightning interviews run alongside workshops at 13:00–15:00. The closing ceremony runs 17:30–20:30. |

- **The partner exhibition is not the project expo.** Partner exhibits run only before the Day 1 opening. On Day 5, each team that submits a project gets a table to demo for visitors and judges.
- **Interviews do not take time away from the expo or judging.** Lightning interviews are opt-in, last 10 minutes, and run in a separate space during the afternoon workshops. They do not count toward competition scores.
- **Roster lock is not the submission deadline.** Teams can keep working after Day 4’s roster lock until the Day 5 cutoff. A single project may enter more than one [open track](tracks.md).

Confirmed venue hours, meals, lodging, and overnight access will be covered in the arrival guide.
