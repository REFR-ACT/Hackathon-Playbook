# REFR/ACT 执行手册

[中文首页](../../README.zh.md) / [English](../en/operations.md)

这份手册写的是本届准备怎么做，不是往届战报。[线下排期](schedule.md)是对外日程的统一入口；这里记录负责人、验收方式和备用安排。未确认的日期、场地和报名细则在对外材料中标明状态。

## 1. 活动边界

DAY 0 布展与联调，DAY 1–5 为线下活动。报名面向所有创作者，不以学生身份、学校或专业作限制。团队自定项目，提交可演示的原型和简短的过程说明。企业赛道、产品试用和面谈均为自愿。

开报名以前先确认：场地与容量、各区开放时段、团队人数规则、无障碍与安全安排、报名和取消方式、奖项与评审流程。合作方不能先替组织者承诺这些安排。

## 2. 谁来负责

| 工作 | 必须交付 |
| --- | --- |
| 总协调 | 倒排总表、决策记录、风险清单和对外口径。 |
| 场地与安全 | 工位和各区平面图、位置与容量核验、应急联系人。 |
| 参赛者与导师 | 行前指南、组队流程、导师值班与求助方式。 |
| 评审与作品展 | 提交清单、评委说明、回避规则和展位分配表。 |
| 技术与物料 | 普通参赛设备的联网与提交实测，备用收件、设备借还台账。 |
| 合作与财务 | 确认单、到场联系人、物资发放记录、专项奖与赞助权益单列、赛后回执。 |

每项交付指定一名负责人和一个备份。会上留下做什么、谁接、哪天验收，避免所有人都知道问题却没人接手。

## 3. 倒排时间线

| 节点 | 完成标志 |
| --- | --- |
| 报名开放前 | 日期、场地、容量、现场监管与财务确认；公告包含报名条件、组队规则和基本日程。 |
| 合作定稿前 | 签署协议，写明工作范围、完成标准、资源、使用条件与回执。企业赛道另备公开说明，列明方向、提交要求、评审规则和专项奖。 |
| 开赛前一周 | 走查网络与供电；测试报名、签到、提交和计分；发布参赛指南，确认联系人、展桌和备份。 |
| 赛后 | 闭幕后 10 个工作日内交付约定的合作回执；归还设备、对账、核查授权并复盘。 |

## 4. 正式开赛前的试跑

用一台普通参赛设备走一遍入场、联网、拿样例、提交和现场演示。让不熟悉流程的人照指南操作，记录卡点及修复人。必要时安排短时演练；演练不替代正式提交和评审。

## 5. 场地、人员与安全

- 确认开发区、技术桌、作品展、舞台、面谈区、休息区和通道的位置。面谈区与评审动线分开。
- 先查容量、供电、无障碍路线、饮食过敏信息、设备操作条件和现场应急联系人。未成年人参与按活动正式公布的授权和现场监管规则执行。
- 活动时段、场地和安全安排由负责人员确认。提供助理或导师的人不能代替现场安全监管。

## 6. 预算与合作伙伴

分开记制作、场地、餐饮、硬件与耗材、宣传物料及奖项。列数量、用途、支付方式和负责人；没有书面确认的合作不计入可用预算。

品牌露出、设备与工具、技术桌、产品试用和联合工坊的交付分别写进协议。企业可单独合作一个[公开赛道](tracks.md)，发布一个开放方向和自定规则。专项奖由企业另行提供奖金或等值产品并指定评委，与主赛奖项分开记账和评审。[企业与社区合作](partnerships.md)介绍了不同合作方式。

## 7. 报名与参与者沟通

报名期从赛前开放报名到截止。报名页写清所需资料、审核与通知安排、组队方式，以及未成年人参与、饮食和无障碍安排。审核看报名动机和想做的方向；已有作品可以附上，不作硬性要求，不按学校筛选。通过审核后由组委会发出参赛确认。只收办活动需要的信息，不向合作方提供报名名单。

确认邮件和行前指南说明席位、签到时段与入口、需携带物品、场地开放时段、餐饮、无障碍安排与现场求助。行前指南和现场提醒链接到同一版日程与规则。参赛者可独自申请，DAY 1 有组队环节。团队可自愿报名多个企业赛道，无须使用合作方工具。

## 8. 技术与物资

- 用普通参赛设备测试网络、登录、权限、工具额度及提交回执，留一条离线或备用收件路径。
- 测投影、音频、计时屏和转接头；核查供电与设备使用安全，备好借还登记。
- 工具优先提供能直接运行的样例。确认额度的适用地区、资格、有效期、并发及数据规则。
- 每次测试留设备、步骤、结果、卡点与修复人。

## 9. 提交与评审

团队可做软件、硬件、游戏或交互等原型。提交内容包括项目说明、可演示的核心流程、团队做过的主要取舍以及能说明成败的测试记录。不要把曾经成功一次说成可上线。

**DAY 5 上午全员作品展与展评。** 每支提交作品的队伍有独立展位和同等的演示机会。赛前公布提交要求、评委回避、评分项以及同分和迟交处理；主赛评委用同一套规则。专项赛道另行评审。使用合作方工具、参加赛道或人才面谈，均不影响主赛评分。

## 10. 活动当天怎么运行

| 日程 | 筹备组要核对的事项 |
| --- | --- |
| DAY 0 · 筹备 | 联调场地、设备、网络、提交与备用通道，核对工位与展位。 |
| DAY 1 · 入场与开幕 | 签到，运行开幕前合作伙伴展；发布现场指南、开放组队提交和开发。 |
| DAY 2 · 开发与工坊 | 导师巡场，运行可选工坊和技术桌，留出连续制作时间。 |
| DAY 3 · 制作与交流 | 组织工坊和跨队互试，为团队留出修改时间；开放自愿的闪电面试预约。 |
| DAY 4 · 锁队 | 锁定队伍信息，提醒作品提交截止；关闭预约并发出面谈时段。 |
| DAY 5 · 全员作品展与闭幕 | 截止收件后核对展位；上午全员展评，下午在独立区域安排面试，与工坊并行；晚间闭幕并记录奖项。 |

现场运行表只保留时间、动作、负责人、备用人和状态。若规则或时段临时调整，统一通知所有受影响的团队。

## 11. 出了问题怎么办

| 情况 | 处理方式 |
| --- | --- |
| 网络或工具不可用 | 开备用网络或离线路径，记录影响范围；如确需延时，统一通知。 |
| 提交入口故障 | 用预先宣布的备用通道收件并记录时间，所有队伍适用同一规则。 |
| 导师、评委缺席 | 按候补顺序补位，检查回避关系与所有队伍的演示时长。 |
| 身体不适或现场安全问题 | 联系场地与活动安排中的应急负责人，现场先保障人员安全。 |
| 资源未到或预算变化 | 停止未确认的采购或承诺，联系相应伙伴，改用确认过的备用资源。 |

## 12. 收尾与复盘

核对设备归还、奖项发放与赞助履约。赛后回执附品牌露出的链接、截图与可验证数据，并按协议整理资源使用、匿名反馈、赛道作品及人才对接。平台数据与现场签到分别统计。作品和个人资料只在授权范围内分享。

复盘时记录一次具体的卡点和解决办法。下次谁负责、什么时候完成，也写下来。
