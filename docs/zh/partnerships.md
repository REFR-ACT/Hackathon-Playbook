# 企业与社区合作

[中文首页](../../README.zh.md) / [English](../en/partnerships.md)

合作方可以带来设备、工具额度或一位愿意现场答疑的工程师；社区也可以协助招募、组织交流或推荐导师。我们先把合作内容、双方分工和完成标准写进协议，再安排现场和传播。

## 学校与社团怎么参与

学校、实验室、创客空间和学生社团可以参与招募、导师答疑、设备借用或作品展交流，不必先选赞助档。欢迎介绍你所在的机构、想参与的环节以及可以投入的时间或资源。

## 合作方式

| 合作方式 | 在上一档基础上，可以新增什么 |
| --- | --- |
| **T4 · 资源伙伴** | 提供设备、额度、耗材、技术支持或其他等值资源；在官网、现场伙伴鸣谢区和赛后回顾署名，并收到传播回执。本档不含伙伴展位。 |
| **T3 · 支持伙伴** | 可加入招募期合作方介绍与链接，并在 DAY 1 开幕前的合作伙伴展设公开展位。 |
| **T2 · 活动伙伴** | 新增社交平台品牌与产品专帖、独立传播位、技术桌或自愿产品体验、DAY 5 作品展交流，以及一个[公开赛道](tracks.md)。组委会提供一个飞书选手群和一个 Discord 选手群，用于发布资源和技术答疑。 |
| **T1 · 共创伙伴** | 包含 T2，新增主视觉重点署名、开闭幕式主持鸣谢、官方专题内容、联合工坊或专题活动，以及 DAY 5 下午的闪电面试。 |

**方向独家冠名**独立于 T1–T4。独家范围限于约定方向，例如「REFR/ACT 智能硬件独家冠名合作伙伴」，不覆盖整个活动。冠名可出现在官网、相关主视觉、现场物料和传播内容；开闭幕式合作方致辞仅向方向独家冠名伙伴开放。可按协议增加跨平台联合传播，并与自愿授权的成年参赛者建立后续联系。

## 单独合作一个公开赛道

企业也可不选赞助档，单独合作一个公开赛道。企业定一个开放方向，自定提交要求、评审规则和专项奖；团队自行决定做什么，同一项目可以参加多个赛道。专项奖由企业另行提供奖金或等值产品，由企业指定评委评选，与主赛奖项分开。更多见[公开赛道说明](tracks.md)。

## 赛后能看到什么

约定的合作回执在闭幕后 **10 个工作日内**交付。品牌露出附发布链接、截图和可核验数据：社交平台按各自后台口径分别统计，现场以实际签到为准，不与线上展示相加。技术体验、专项赛道和人才对接按实际开展情况整理；作品与个人资料按授权范围分享。

闪电面试自愿预约，每场 10 分钟。从作品和参赛者实际负责的部分聊起。双方都有意愿、参赛者同意后，组委会再安排企业初面转接。面试与评审分开，不提供报名名单。
