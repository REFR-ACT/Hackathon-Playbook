# 企业与社区合作

[回到中文首页](../../README.zh.md) / [English](../en/partnerships.md)

贵方可以带一套设备、一项工具或一位工程师来。如果手里没有合适的产品，也可以只带一道值得验证的业务题。资源、到场安排和赛后的材料，合作前逐项写清。

## 学校与社团怎么参与

如果你代表学校、实验室、创客空间或学生社团，欢迎来聊跨校招募、导师答疑、设备借用或作品展交流。不必先选择赞助档位。发邮件说说你代表的机构、希望参与哪个环节，以及可投入的时间或资源。是否合作及具体安排以双方确认结果为准。

## 赞助合作

| 方式 | 贵方可以参与哪些环节 |
| --- | --- |
| T4 资源伙伴 | 提供设备、额度、耗材或技术支持；获得活动页与回顾署名、传播记录及赛后回执。 |
| T3 支持伙伴 | 在基础权益上增加活动页企业简介与链接。 |
| T2 活动伙伴 | 增加招募或现场露出、作品展交流席，以及技术桌或产品试用。试用自愿；按约反馈匿名汇总。 |
| T1 共创伙伴 | 在 T2 之上增加主视觉署名、现场鸣谢、联合工作坊或共创专题，以及闪电面试合作，场次待公布。 |

闪电面试另设面谈区。伙伴提前提供岗位方向，创作者自愿预约，每人 10 分钟，从作品和创作者实际负责的部分聊起。双方同意后才交换联系方式；不共享报名名单，不计入评审，不承诺录用。

## 企业也可以单独出题

不选赞助档，也可以提出一项共创命题。先把实际场景和一位业务联系人带来：双方用一页说明定清验证范围、可公开或脱敏的样例、测试条件、演示要求和资源限制。筹备组负责发布、协调答疑及整理验证记录，团队可以自主选择是否参加。

企业可为自己提出的命题另设专项奖，奖金由命题方另行出资。金额、评选和发放方式在开赛前写入确认单。专项奖金不是赞助档位的一部分，也不改变正赛评分。

## 会有哪几样材料

- **品牌露出**：约定的位置、发布链接、截图和可查数据。活动页访问、平台展示与现场实际签到人数分开记。
- **资源使用**：按合作内容记录借还、额度发放及可查兑换量。开展产品试用的合作另有匿名反馈汇总。
- **命题成果**：按约交付原型运行或演示说明、验证记录与限制。作品、照片与其他素材先获授权，再交付。后续开发另议。

报价、回执日期与具体权益按书面合作确认单执行。我们不在公开页面承诺触达、产品用量或招聘结果。

我们欢迎来自中国、美国及其他地区的合作伙伴。可以先发邮件到 [contact@refracthack.org](mailto:contact@refracthack.org)，说说想带来的资源或问题，第一次可以约线上聊。报价、合同、个人资料和未公开业务数据请不要贴到公开 Issue。
