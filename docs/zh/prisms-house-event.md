# PRISMS House Event：Jones’s Bizarre Adventure

[手册首页](../../README.zh.md) / [English](../en/prisms-house-event.md)

Jones’s Bizarre Adventure 是 PRISMS 校内学院游戏赛，与 [REFR/ACT 五天线下黑客松](schedule.md)分开举办。校内赛的日期、提交要求和评审以[官方规则](https://refracthack.org/housegame/?lang=zh)为准，不套用主赛手册。

## 每个学院做什么

每个学院组一队，提交一款 Python 游戏。主题在启动时公布，开发时间约三周。游戏的核心玩法必须能用一支摇杆和八个动作按钮完成，无需键盘或鼠标。

| 节点 | 团队准备什么 |
| --- | --- |
| 第 1 周 | 游戏构想、玩法设计、团队分工和 GitHub 仓库。 |
| 第 2 周 | 能从头到尾玩完一轮的原型。 |
| 第 3 周 | 最终游戏，附仓库链接和运行说明。 |
