# REFR/ACT 线下排期

[回到中文首页](../../README.zh.md) / [English](../en/schedule.md)

**DAY 1 布展，DAY 2–DAY 5 全程线下。** 本届面向校园社区，不限于一所学校。正式参赛资格和监护要求以报名公告为准。活动计划于 **2027 年春季**在美国新泽西州普林斯顿地区举办，预计 **500 名创造者**。选手报名暂未开放；具体日期、场地、选手报名入口和每天时段将在确认后从本页发布。[筹备组招募](../../README.zh.md#refract-2027-筹备组招募)独立开放，不是参赛报名。

如果你在找 [PRISMS House Event（校内学院游戏赛）](prisms-house-event.md)，请查看该活动自己的赛程和提交规则。

| 日程 | 参赛者和合作方到场后做什么 |
| --- | --- |
| DAY 1 · 布展 | 筹备组与合作方布展，联调网络、设备及提交通道，准备技术桌和展示位置。 |
| DAY 2 · 开幕 | 签到，说明提交和评审要求，组队，开始做原型。 |
| DAY 3 · 开发 | 保留连续的制作时间，安排导师答疑、可选工作坊和自愿产品试用。拟在正式提交前留一段时间给队伍互试原型。 |
| DAY 4 · 提交与初评 | 作品提交截止，评委按公布的规则进行初评。 |
| DAY 5 · 全员作品展与决赛 | 上午举办全员作品展，每支提交作品的队伍都有自己的展位。之后安排决赛演示、问答、颁奖与闭幕。 |

## 现场的三个关键时点

- **DAY 3 技术桌**：有实际接入问题，可以带设备和代码过来。工作坊不占掉整段制作时间。
- **DAY 5 上午 · 全员作品展**：带一个别人可以上手的原型。展示已经完成的部分，也说清楚哪一步没跑通。
- **DAY 5 决赛**：展示核心流程，再回答评委的问题。与合作方交流或参加面谈都不计入竞赛评分。

闪电面试另设区域，参加者自愿预约，具体场次待公布。企业命题也不是必选项；面谈和选择企业命题均不影响评审。[了解企业如何参与](partnerships.md)，或查阅[公开执行手册](operations.md)。
