# REFR/ACT 2027 线下日程

[中文首页](../../README.zh.md) / [English](../en/schedule.md)

**五天线下活动，另设一天布展。** 活动计划于 2027 年 3 月下旬在美国新泽西州普林斯顿地区举办。下表是按当地时间编排的拟定流程；具体日期、场地及最终日程由[活动官网](https://refracthack.org)公布。

**选手报名尚未开放。** 报名期在活动前，从开放报名到截止，不计入 DAY 0–5。报名入口开放后会在本页同步，审核见[参赛者指南](participant-experience.md)。[筹备组招募](../../README.zh.md#refract-2027-筹备组招募)是独立入口，不是选手报名。

| 日程 | 拟定安排 |
| --- | --- |
| **DAY 0 · 筹备** | 组委会准备场地、联调设备和网络，并进行开幕彩排。 |
| **DAY 1 · 入场与开幕** | 09:00 合作方入场布展，10:00 参赛者入场与合作伙伴展开场。展会 16:00 结束，18:30–22:00 开幕式。22:00 开放组队信息提交，开幕后进入开发。 |
| **DAY 2 · 开发与工坊** | 保留连续开发时间，穿插上手工坊、跨队试用和交流。工坊自愿参加。 |
| **DAY 3 · 制作与交流** | 继续开发，安排交互与原型改造工坊。16:00 开放闪电面试预约。 |
| **DAY 4 · 锁队与演示准备** | 12:00 锁定队伍信息，作品仍可继续提交。16:00 面试预约截止，18:30 发放面谈时段。 |
| **DAY 5 · 全员作品展与闭幕** | 01:00 作品提交截止。09:00–11:30 全员作品展与展评；13:00–15:00 闪电面试与工坊并行；17:30–20:30 闭幕式。 |

- **合作伙伴展和作品展是两件事。** 合作伙伴展只在 DAY 1 开幕前开放。DAY 5 上午给每支提交作品的队伍安排展位，让来访者上手体验，评委也在这里看作品。
- **面试不占用展评时间。** 闪电面试自愿预约，每人 10 分钟，在下午与工坊并行，单独安排动线，不计入竞赛评分。
- **锁队不是提交截止。** DAY 4 锁定的是队伍信息；此后仍可改作品，直至 DAY 5 的提交截止。一个项目可自愿报名多个[公开赛道](tracks.md)。

场地开放时段、餐饮、住宿及夜间安排随行前指南确认。
