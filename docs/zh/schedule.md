# REFR/ACT 线下排期

[回到中文首页](../../README.zh.md) / [English](../en/schedule.md)

**DAY 1 布展，DAY 2–DAY 5 全程线下。** 本届面向所有创作者，不以学校、学生身份或专业作为报名限制。日历日期、场地、报名入口及每天的具体时段将在确认后从本页发布。目前仅开放信息查询，本页不等于报名已开放。

| 日程 | 参赛者和合作方到场后做什么 |
| --- | --- |
| DAY 1 · 布展 | 筹备组与合作方布展，联调网络、设备及提交通道，准备技术桌和展示位置。 |
| DAY 2 · 开幕 | 签到，说明提交和评审要求，组队，开始做原型。 |
| DAY 3 · 开发 | 保留连续的制作时间，安排可选工作坊、导师答疑和自愿产品试用。 |
| DAY 4 · 展评 | 先截止提交，再开作品展。创作者在桌边演示，评委按公开规则初评。闪电面试另设区域，参加者自愿预约。 |
| DAY 5 · 决赛 | 入围团队做现场演示与问答，随后颁奖、闭幕。 |

## 现场的三个关键时点

- **DAY 3 技术桌**：有实际接入问题，可以带设备和代码过来。工作坊不占掉整段制作时间。
- **DAY 4 作品展**：带一个别人可以上手的原型。展示已经完成的部分，也说清楚哪一步没跑通。
- **DAY 5 决赛**：展示核心流程，再回答评委的问题。与合作方交流或参加面谈都不计入竞赛评分。

企业命题不是必选项。参与者可自由选题；招聘面谈也不影响参赛资格和晋级。[了解企业如何参与](partnerships.md)，或查阅[公开执行手册](operations.md)。
