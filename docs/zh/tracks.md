# 公开赛道：企业给方向，团队做决定

[中文首页](../../README.zh.md) / [English](../en/tracks.md)

企业赛道给作品一个可探索的方向。例如 **「让随身设备读懂日常」**：想让设备理解什么、帮助谁、最后做成什么样，都由参赛团队决定。它不是一道指定题，也不要求团队使用指定产品。设备、工具和技术支持可以另行提供，团队自行选择是否使用。

## 一件作品可以报几个赛道？

**同一个项目可以报名多个赛道。** 团队先看赛前公布的规则，选择与作品有关的方向，按各赛道的提交要求分别参评。也可以不报名任何企业赛道，只参加主赛。有没有报企业赛道、用了什么合作方工具，都不影响主赛评分。

## 规则和奖项由谁定？

| 谁 | 负责什么 |
| --- | --- |
| 合作企业 | 给出一个开放方向，自定作品提交要求、评审标准与专项奖。专项奖由企业另行提供奖金或等值产品，由企业指定的评委按公开规则评选。 |
| 组委会 | 赛前发布署有企业名称的赛道说明和规则，组织报名、提交与现场展示。主赛按统一规则独立评审。 |
| 参赛团队 | 自选问题、实现方式和作品形态。报名多个赛道时，查清各自的提交要求并分别参评。 |

公开赛道不转移作品权利。组委会只按授权分享作品或个人资料。[企业合作与赛后交付](partnerships.md)介绍企业如何参与。
